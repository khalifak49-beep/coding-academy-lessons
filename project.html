ماذا يفعل هذا الكود؟ هيكل برنامج المشروع النهائي: قائمة نصية تتكرر حتى يختار المستخدم 0، وكل رقم يستدعي دالة تتعامل مع قاعدة البيانات SchoolDB. دالتا العرض والإضافة جاهزتان، وعليك إكمال التعديل والحذف والإحصائيات.

  1. using Microsoft.Data.SqlClient; توجيه using يستورد مكتبة Microsoft.Data.SqlClient لنستخدم SqlConnection و SqlCommand للتعامل مع SQL Server.
  2. Console.OutputEncoding = System.Text.Encoding.UTF8; نضبط ترميز الطباعة في الشاشة على UTF8 حتى تظهر الحروف العربية والرموز بشكل صحيح بدل علامات استفهام.
  3. string cs = @"Server=localhost\SQLEXPRESS;Database=SchoolDB;Trusted_Connection=True;TrustServerCertificate=True;"; نص الاتصال بقاعدة البيانات: Server اسم الخادم (نسخة SQLEXPRESS على جهازك)، و Database هي SchoolDB، و Trusted_Connection=True للدخول بحساب Windows، و TrustServerCertificate=True لقبول شهادة الخادم المحلي. علامة @ تجعل \ حرفًا عاديًا. نعرّفه مرة واحدة وتستخدمه كل الدوال.
  4. string choice = ""; متغير يحفظ اختيار المستخدم، نبدأه بنص فارغ حتى يكون مختلفًا عن "0" فتبدأ الحلقة.
  5. while (choice != "0") حلقة while تكرر عرض القائمة ما دام اختيار المستخدم ليس "0". عندما يكتب 0 يتوقف التكرار وينتهي البرنامج.
  6. { القوس { يبدأ جسم الحلقة، أي الأوامر التي تتكرر في كل دورة، والقوس } المقابل ينهيه.
  7. Console.WriteLine("\n===== نظام سجل الطلاب ====="); نطبع عنوان القائمة. الرمز \n داخل النص يعني سطرًا جديدًا، فيترك سطرًا فارغًا قبل العنوان لتنظيم الشاشة.
  8. Console.WriteLine("1) عرض الطلاب 2) إضافة طالب 3) تعديل درجة"); هذا السطر والذي بعده يطبعان خيارات القائمة مع رقم كل خيار.
  9. Console.Write("اختيارك: "); نطلب من المستخدم كتابة رقم الخيار، و Write تبقيه على نفس السطر.
  10. choice = Console.ReadLine(); نقرأ ما كتبه المستخدم ونحفظه في choice. لاحظ أننا لا نكتب string هنا لأن المتغير معرّف مسبقًا.
  11. switch (choice) الأمر switch يقارن قيمة choice بعدة حالات ويُنفّذ الحالة المطابقة، وهو أوضح من كتابة if كثيرة.
  12. case "1": ShowAll(); break; هذا السطر والسطران بعده: إذا كان الاختيار "1" نستدعي ShowAll، و"2" نستدعي AddStudent، و"3" نستدعي UpdateGrade. الكلمة break تُنهي switch (وليس الحلقة) فنعود لعرض القائمة.
  13. case "4": DeleteStudent(); break; هذا السطر والذي بعده: "4" يستدعي DeleteStudent لحذف طالب، و"5" يستدعي Stats للإحصائيات.
  14. case "0": Console.WriteLine("وداعًا"); break; إذا اختار 0 نطبع رسالة وداع، ثم يتحقق شرط الحلقة فتتوقف لأن choice أصبح "0".
  15. default: Console.WriteLine("اختيار غير صحيح"); break; الحالة default تُنفّذ إذا لم يطابق الاختيار أيًا من الحالات السابقة، فننبّه المستخدم ونعيد القائمة.
  16. void ShowAll() نعرّف دالة اسمها ShowAll لعرض كل الطلاب. void تعني أنها لا تعيد قيمة. هي دالة محلية مكتوبة بعد الكود الرئيسي ويمكنها استخدام المتغير cs.
  17. using var conn = new SqlConnection(cs); ننشئ اتصالًا بقاعدة البيانات، و using var تغلقه تلقائيًا عند نهاية الدالة.
  18. conn.Open(); نفتح الاتصال بالخادم فعليًا.
  19. var cmd = new SqlCommand("SELECT Id, FullName, Course, Grade FROM Students", conn); نجهّز أمر SELECT يجلب رقم الطالب واسمه ودورته ودرجته، ونربطه بالاتصال.
  20. using var r = cmd.ExecuteReader(); ExecuteReader تنفّذ الاستعلام وتعيد قارئًا r لقراءة النتائج صفًا صفًا.
  21. while (r.Read()) r.Read() تنتقل للصف التالي وتعيد true ما دامت هناك صفوف، فنكرر الطباعة لكل طالب.
  22. Console.WriteLine($"{r["Id"]}. {r["FullName"]} | {r["Course"]} | {r["Grade"]}"); نطبع بيانات الطالب الحالي، و r["Id"] مثلًا تجلب قيمة العمود Id من الصف الحالي. علامة $ تسمح بوضع القيم داخل { }.
  23. void AddStudent() دالة AddStudent تطلب بيانات طالب جديد وتضيفه إلى قاعدة البيانات.
  24. Console.Write("الاسم: "); string name = Console.ReadLine(); في سطر واحد: نطبع سؤال الاسم ثم نقرأ إجابة المستخدم ونحفظها في name. يمكن كتابة أمرين في سطر لأن كلًا منهما ينتهي بفاصلة منقوطة.
  25. Console.Write("الدورة: "); string course = Console.ReadLine(); بنفس الطريقة نسأل عن الدورة ونحفظها في course.
  26. Console.Write("الدرجة: "); نطلب إدخال الدرجة.
  27. if (!decimal.TryParse(Console.ReadLine(), out decimal grade)) decimal.TryParse تحاول تحويل النص إلى رقم عشري: إن نجحت تعيد true وتضع الرقم في grade (عبر out)، وإن فشلت تعيد false دون أن يتوقف البرنامج. العلامة ! تعني "ليس"، أي: إذا فشل التحويل.
  28. Console.WriteLine("درجة غير صحيحة"); return; إذا كانت الدرجة غير صالحة نطبع تنبيهًا، ثم return تخرج من الدالة فورًا دون إضافة شيء لقاعدة البيانات.
  29. using var conn = new SqlConnection(cs); بعد التأكد من صحة المدخلات ننشئ الاتصال، و using var تغلقه تلقائيًا.
  30. conn.Open(); نفتح الاتصال.
  31. var cmd = new SqlCommand( ننشئ أمر SqlCommand على سطرين لطول النص.
  32. "INSERT INTO Students (FullName, Course, Grade) VALUES (@n, @c, @g)", conn); أمر الإضافة يستخدم معاملات @n و @c و @g بدل القيم الحقيقية، وهي أماكن محجوزة تُملأ بأمان في الأسطر التالية.
  33. cmd.Parameters.AddWithValue("@n", name); هذا السطر والسطران بعده يربطون كل معامل بقيمته: @n بالاسم و @c بالدورة و @g بالدرجة. القيم تُرسل كبيانات منفصلة عن نص الأمر، فلا يمكن تنفيذها كأوامر SQL، وهذا يحمي من هجوم SQL Injection.
  34. cmd.ExecuteNonQuery(); ExecuteNonQuery تنفّذ أمر INSERT فعليًا. هي للأوامر التي لا تعيد جدول نتائج، وتعيد عدد الصفوف المتأثرة (لم نحفظه هنا).
  35. Console.WriteLine("تمت الإضافة ✔"); نطبع رسالة تأكيد للمستخدم بنجاح الإضافة.
  36. // أكمل أنت: UpdateGrade و DeleteStudent و Stats السطر الذي يبدأ بـ // تعليق لا ينفّذه ⁦C#⁩. هنا يخبرك أن الدوال الثلاث التالية عليك إكمالها بنفسك.
  37. void UpdateGrade() { /* UPDATE Students SET Grade = @g WHERE Id = @id */ } دالة فارغة الآن، وداخل /* */ تعليق يلمّح للأمر المطلوب: UPDATE مع معاملين @g و @id. اقرأ رقم الطالب ودرجته الجديدة ثم استخدم ExecuteNonQuery، ولا تنسَ WHERE حتى لا تتغير درجات الجميع.
  38. void DeleteStudent() { /* DELETE FROM Students WHERE Id = @id */ } دالة الحذف: اقرأ رقم الطالب ونفّذ DELETE بمعامل @id عبر ExecuteNonQuery. شرط WHERE هنا ضروري جدًا، فبدونه تُحذف كل الصفوف.
  39. void Stats() { /* SELECT COUNT(*), AVG(Grade), MAX(Grade) FROM Students */ } دالة الإحصائيات: الاستعلام يعيد صفًا واحدًا بثلاث قيم (العدد والمتوسط وأعلى درجة)، فيمكنك قراءته بـ ExecuteReader ثم r.Read() مرة واحدة، أو تنفيذ ثلاثة استعلامات بـ ExecuteScalar.
