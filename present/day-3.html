تنسيق الصفحات بـ CSS

في نهاية الدرس ستستطيع أن:

  • يربط ملف CSS بصفحة HTML.
  • يستخدم المحددات: الوسم والكلاس class والمعرّف id.
  • يغير الألوان والخطوط والخلفيات.
  • يفهم نموذج الصندوق: margin وborder وpadding.
  • يرتب العناصر أفقيًا باستخدام Flexbox.

ما هو CSS وكيف نربطه؟

HTML يحدد المحتوى، وCSS يحدد الشكل. نكتب CSS داخل وسم style أو في ملف مستقل style.css نربطه بالصفحة.

HTML 
<head>  <link rel="stylesheet" href="style.css"></head>
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يوضح هذا المثال كيف نربط صفحة HTML بملف تنسيق خارجي اسمه style.css، فتأخذ الصفحة ألوانها وشكلها من هذا الملف. لا يظهر شيء جديد بنفسه، لكن التنسيقات المكتوبة في الملف تُطبَّق على الصفحة.

  1. <head> قسم head هو المكان المناسب لربط ملفات التنسيق، لأنه يحتوي معلومات الصفحة التي يقرؤها المتصفح قبل عرض المحتوى.
  2. <link rel="stylesheet" href="style.css"> الوسم link يربط الصفحة بملف آخر. الخاصية rel="stylesheet" تقول إن هذا الملف ملف تنسيق CSS، والخاصية href تحدد اسم الملف style.css، ويجب أن يكون في نفس مجلد صفحة HTML في هذا المثال.
  3. </head> يغلق قسم head.

المحددات والخصائص

القاعدة تتكون من محدد ثم خصائص بين أقواس. الكلاس يبدأ بنقطة . ويمكن تكراره، والمعرّف يبدأ بـ # ويُستخدم مرة واحدة.

HTML 
<style>  body { font-family: Tahoma; background: #f5f5f5; }  h1 { color: darkblue; text-align: center; }  .highlight { background: yellow; }  #intro { font-size: 20px; color: #444; }</style> <h1>مرحبًا بكم</h1><p id="intro">هذه فقرة تعريفية.</p><p>هذه فقرة فيها <span class="highlight">كلمة مميزة</span>.</p>
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يكتب هذا المثال تنسيق CSS داخل الصفحة نفسها: خلفية رمادية فاتحة وخط Tahoma للصفحة، وعنوان أزرق داكن في الوسط، وفقرة تعريفية أكبر بلون رمادي، وكلمة مميزة بخلفية صفراء.

  1. <style> الوسم style يسمح بكتابة تنسيقات CSS داخل ملف HTML نفسه. كل ما بين <style> و</style> قواعد تحدد شكل العناصر، ولا يظهر كنص على الشاشة.
  2. body { font-family: Tahoma; background: #f5f5f5; } هذه قاعدة CSS: كلمة body هي «المحدِّد» أي العنصر الذي نريد تنسيقه، وبين القوسين { } خصائص. font-family تجعل خط الصفحة Tahoma، وbackground تجعل الخلفية بلون #f5f5f5 وهو رمادي فاتح جدًا مكتوب بنظام الألوان السداسي (hex).
  3. h1 { color: darkblue; text-align: center; } تنسيق كل عناوين h1: الخاصية color تجعل لون النص أزرق داكنًا (darkblue)، والخاصية text-align: center تضع النص في منتصف السطر. لاحظ أن كل خاصية تنتهي بفاصلة منقوطة ;.
  4. .highlight { background: yellow; } النقطة قبل الاسم تعني أن هذا محدِّد «كلاس» (class)، فيُطبَّق التنسيق على أي عنصر مكتوب فيه class="highlight". هنا يجعل خلفيته صفراء مثل قلم التظليل.
  5. #intro { font-size: 20px; color: #444; } علامة # تعني محدِّد «معرّف» (id)، فيُطبَّق على العنصر الذي يحمل id="intro"، والمعرّف يُستخدم لعنصر واحد فقط في الصفحة. font-size: 20px تجعل حجم الخط 20 بكسل، وcolor: #444 لون رمادي غامق.
  6. </style> يغلق وسم التنسيق، وبعده يبدأ محتوى الصفحة الذي سيتأثر بهذه القواعد.
  7. <h1>مرحبًا بكم</h1> عنوان h1 سيظهر بلون أزرق داكن وفي منتصف الصفحة بسبب قاعدة h1 أعلاه.
  8. <p id="intro">هذه فقرة تعريفية.</p> فقرة تحمل المعرّف id="intro"، لذلك ستأخذ تنسيق #intro فتظهر بخط أكبر (20 بكسل) ولون رمادي غامق.
  9. <p>هذه فقرة فيها <span class="highlight">كلمة مميزة</span>.</p> الوسم span حاوية صغيرة تحيط بجزء من النص دون أن تنقله إلى سطر جديد. لأنه يحمل class="highlight" ستظهر عبارة «كلمة مميزة» بخلفية صفراء وباقي الفقرة عادي.

نموذج الصندوق (Box Model)

كل عنصر هو صندوق: المحتوى ثم padding (المسافة الداخلية) ثم border (الإطار) ثم margin (المسافة الخارجية).

HTML 
<style>  .card {    background: white;    padding: 20px;    border: 2px solid #3b82f6;    border-radius: 12px;    margin: 20px;    width: 250px;  }</style><div class="card">  <h3>سارة أحمد</h3>  <p>متدربة في دورة البرمجة</p></div>
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يصنع هذا المثال «بطاقة» بخلفية بيضاء وإطار أزرق وزوايا دائرية، وبداخلها اسم المتدربة ووصف قصير.

  1. <style> بداية قسم تنسيقات CSS داخل الصفحة.
  2. .card { بداية قاعدة للكلاس card؛ كل عنصر يحمل class="card" سيأخذ الخصائص المكتوبة في الأسطر التالية. هنا كتبنا كل خاصية في سطر لتسهيل القراءة.
  3. background: white; الخاصية background تجعل خلفية البطاقة بيضاء.
  4. padding: 20px; الخاصية padding هي المسافة الداخلية بين حدود البطاقة ومحتواها، وهنا 20 بكسل من كل الجهات حتى لا يلتصق النص بالإطار.
  5. border: 2px solid #3b82f6; الخاصية border ترسم إطارًا حول البطاقة: سُمكه 2px، ونوعه solid أي خط متصل، ولونه #3b82f6 وهو أزرق.
  6. border-radius: 12px; الخاصية border-radius تجعل زوايا البطاقة دائرية بدل أن تكون حادة، وكلما زاد الرقم زاد انحناء الزوايا.
  7. margin: 20px; الخاصية margin هي المسافة الخارجية حول البطاقة، أي الفراغ بينها وبين ما حولها، وهنا 20 بكسل.
  8. width: 250px; الخاصية width تحدد عرض البطاقة بـ 250 بكسل، بدل أن تمتد على عرض الصفحة كلها.
  9. } القوس } يغلق قاعدة .card، فكل الخصائص بين القوسين تابعة لها.
  10. <div class="card"> الوسم div حاوية عامة نجمع بداخلها عناصر أخرى. لأنه يحمل class="card" سيظهر بشكل البطاقة الموصوف في التنسيق.
  11. <h3>سارة أحمد</h3> عنوان h3 داخل البطاقة يعرض اسم المتدربة.
  12. <p>متدربة في دورة البرمجة</p> فقرة داخل البطاقة تعرض وصفًا قصيرًا تحت الاسم.
  13. </div> يغلق الحاوية div، فالعنوان والفقرة كلاهما داخل البطاقة.

ترتيب العناصر بـ Flexbox

display: flex يضع العناصر الأبناء بجانب بعضها. gap يضع مسافة بينها، وjustify-content يحدد توزيعها.

HTML 
<style>  nav { display: flex; gap: 16px; background: #1e293b; padding: 12px; }  nav a { color: white; text-decoration: none; }  nav a:hover { color: #fbbf24; }</style><nav>  <a href="#">الرئيسية</a>  <a href="#">الطلاب</a>  <a href="#">التسجيل</a></nav>
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يصنع هذا المثال شريط تنقل داكنًا فيه ثلاثة روابط بيضاء متجاورة في صف واحد، ويتغير لون الرابط إلى الأصفر عند مرور الفأرة فوقه.

  1. <style> بداية قسم تنسيقات CSS.
  2. nav { display: flex; gap: 16px; background: #1e293b; padding: 12px; } تنسيق شريط nav: الخاصية display: flex ترتّب العناصر التي بداخله بجانب بعضها في صف واحد، وgap: 16px تضع مسافة 16 بكسل بين كل عنصر والذي يليه. background تعطيه لونًا كحليًا داكنًا، وpadding مسافة داخلية 12 بكسل.
  3. nav a { color: white; text-decoration: none; } المحدِّد nav a يعني «كل رابط a موجود داخل nav» فقط. color: white يجعل لون الروابط أبيض، وtext-decoration: none يزيل الخط الذي يظهر تحت الروابط عادةً.
  4. nav a:hover { color: #fbbf24; } الإضافة :hover تعني «عندما تمر الفأرة فوق العنصر». فعندما تضع الفأرة على أي رابط يتغير لونه إلى #fbbf24 وهو أصفر ذهبي، ويعود أبيض عند إبعادها.
  5. </style> يغلق قسم التنسيقات.
  6. <nav> الوسم nav يمثل شريط التنقل، وسيأخذ الخلفية الداكنة وترتيب flex من التنسيق أعلاه.
  7. <a href="#">الرئيسية</a> رابط a مؤقت (href="#" لا ينقل لصفحة أخرى). هذا الرابط والرابطان بعده يظهرون بجانب بعضهم بلون أبيض بفضل display: flex.
  8. </nav> يغلق شريط التنقل.
:hover تنسيق يظهر عند مرور الفأرة فوق العنصر.

نسّق صفحة التعريف

أضف CSS لصفحة يوم 1: لون خلفية فاتح، عنوان رئيسي بلون مختلف ومتوسط، خط Tahoma، وصورة بحواف دائرية (border-radius).

ماذا يفعل هذا الكود؟ يعرض هذا الحل صفحة تعريف بخلفية زرقاء فاتحة، فيها اسم في الوسط بلون أخضر مزرق، وتحته صورة دائرية في منتصف الصفحة، ثم جملة تعريفية.

  1. <style> بداية قسم تنسيقات CSS.
  2. body { background: #eef2f7; font-family: Tahoma; } تنسيق الصفحة كلها: خلفية بلون #eef2f7 (أزرق رمادي فاتح جدًا)، والخط Tahoma.
  3. h1 { color: #0f766e; text-align: center; } العنوان h1 يظهر بلون #0f766e (أخضر مزرق) وفي منتصف السطر بفضل text-align: center.
  4. img { border-radius: 50%; display: block; margin: auto; } تنسيق الصورة: border-radius: 50% يجعل الصورة المربعة دائرة كاملة. display: block يجعل الصورة تأخذ سطرًا خاصًا بها، وmargin: auto يوزع المسافة الفارغة على الجانبين بالتساوي فتصبح الصورة في منتصف الصفحة أفقيًا.
  5. </style> يغلق قسم التنسيقات.
  6. <h1>أحمد علي</h1> عنوان h1 يعرض الاسم بالتنسيق المحدد أعلاه.
  7. <img src="https://placehold.co/150" alt="صورتي"> صورة تجريبية مربعة بحجم 150 بكسل، وستظهر دائرية وفي المنتصف بسبب قاعدة img.
  8. <p>أنا طالب أحب البرمجة.</p> فقرة تعريفية تظهر تحت الصورة.

بطاقات الطلاب

أنشئ 3 بطاقات طلاب (اسم + دورة + درجة) متجاورة باستخدام flex، لكل بطاقة إطار وحواف دائرية ومسافة داخلية.

HTML 
<style>  .cards { display: flex; gap: 16px; flex-wrap: wrap; }  .card { border: 1px solid #ccc; border-radius: 10px; padding: 16px; width: 180px; background: white; }  .card h3 { margin: 0; color: #6d3fc0; }</style><div class="cards">  <div class="card"><h3>سارة</h3><p>C#</p><b>95</b></div>  <div class="card"><h3>خالد</h3><p>HTML</p><b>88</b></div>  <div class="card"><h3>مريم</h3><p>SQL</p><b>91</b></div></div>
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يعرض هذا الحل ثلاث بطاقات طلاب متجاورة في صف، كل بطاقة فيها اسم الطالب ولغته ودرجته، وتنتقل البطاقات إلى سطر جديد إذا ضاقت الشاشة.

  1. <style> بداية قسم تنسيقات CSS.
  2. .cards { display: flex; gap: 16px; flex-wrap: wrap; } تنسيق الحاوية التي تحمل الكلاس cards: display: flex يضع البطاقات بجانب بعضها، وgap: 16px يترك مسافة بينها، وflex-wrap: wrap يسمح للبطاقات بالنزول إلى سطر جديد إذا لم يكفِ عرض الشاشة.
  3. .card { border: 1px solid #ccc; border-radius: 10px; padding: 16px; width: 180px; background: white; } تنسيق كل بطاقة: إطار رمادي فاتح رفيع (1px)، وزوايا دائرية 10 بكسل، ومسافة داخلية 16 بكسل، وعرض ثابت 180 بكسل، وخلفية بيضاء.
  4. .card h3 { margin: 0; color: #6d3fc0; } المحدِّد .card h3 يعني «كل عنوان h3 داخل عنصر له الكلاس card». margin: 0 يلغي المسافة الخارجية التي يضعها المتصفح للعناوين تلقائيًا، وcolor يجعل لونه بنفسجيًا.
  5. </style> يغلق قسم التنسيقات.
  6. <div class="cards"> حاوية div بالكلاس cards تجمع البطاقات الثلاث وترتبها في صف بفضل flex.
  7. <div class="card"><h3>سارة</h3><p>C#</p><b>95</b></div> بطاقة واحدة: div بالكلاس card بداخلها عنوان h3 بالاسم، وفقرة p باللغة، والوسم b يعرض الدرجة 95 بخط عريض. السطران التاليان بطاقتان أخريان بنفس الشكل لخالد ومريم.
  8. </div> يغلق الحاوية الخارجية cards.

  7. form { background: white; padding: 16px; border-radius: 10px; } النموذج form يظهر كصندوق أبيض بمسافة داخلية وزوايا دائرية.

  9. button { background: #0f766e; color: white; border: 0; padding: 8px 20px; border-radius: 6px; } تنسيق الزر: خلفية خضراء مزرقة ونص أبيض، وborder: 0 يزيل الإطار الافتراضي للزر، مع مسافة داخلية وزوايا دائرية ليبدو أجمل.
  10. footer { text-align: center; color: #666; padding: 16px; } التذييل footer نصه في المنتصف وبلون رمادي مع مسافة داخلية.
  11. </style> يغلق قسم التنسيقات، وبعده يبدأ محتوى الصفحة.
  12. <header><h1>نظام سجل الطلاب</h1></header> رأس الصفحة وبداخله العنوان الرئيسي، وسيظهر بشريط أخضر عريض في أعلى الصفحة.

  15. <p>مرحبًا بك في نظام تسجيل الطلاب.</p> فقرة ترحيبية فوق النموذج.
  16. <form> بداية نموذج التسجيل الذي يظهر كصندوق أبيض.
  17. <label>الاسم</label><input type="text"> نص وصفي «الاسم» ثم خانة نصية. لأن عرض الخانة 100% ستنزل تحت النص وتملأ عرض النموذج. والسطر التالي يفعل نفس الشيء لخانة البريد من نوع email.
  18. <label>الدورة</label><select><option>C#</option><option>HTML</option></select> نص وصفي ثم قائمة منسدلة select فيها خياران: ⁦C#⁩ وHTML، وتأخذ نفس تنسيق الخانات.
  19. <button>تسجيل</button> زر «تسجيل» بالتنسيق الأخضر. الزر داخل form بدون type يكون من نوع submit تلقائيًا، أي يرسل النموذج عند الضغط.
  20. </form> يغلق النموذج، والسطر التالي يغلق المحتوى الرئيسي main.
  21. <footer>© 2026</footer> تذييل الصفحة يعرض رمز حقوق النشر © والسنة في منتصف أسفل الصفحة.
