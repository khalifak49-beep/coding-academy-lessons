إنشاء أول مشروع

افتح Visual Studio Community ← Create a new project ← Console App (⁦C#⁩) ← اختر أحدث إصدار .NET يظهر في القائمة ← Create. ثم اضغط F5 أو زر التشغيل الأخضر.

⁦C#⁩ 
// هذا تعليق: لا ينفذه الحاسوبConsole.WriteLine("مرحبًا بالعالم!");Console.WriteLine("أنا أتعلم C#");
مرحبًا بالعالم! أنا أتعلم C#
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ برنامج بسيط يطبع سطرين على الشاشة: «مرحبًا بالعالم!» ثم «أنا أتعلم ⁦C#⁩». السطر الأول تعليق لا يظهر عند التشغيل.

  1. // هذا تعليق: لا ينفذه الحاسوب الرمزان // يبدآن «تعليقًا»، وهو ملاحظة نكتبها للبشر داخل الكود. الحاسوب يتجاهل كل ما بعد // حتى نهاية السطر، فلا يؤثر على عمل البرنامج.
  2. Console.WriteLine("مرحبًا بالعالم!"); Console هي «الشاشة السوداء» التي يكتب فيها البرنامج، و WriteLine أمر يطبع النص الموجود بين القوسين ثم ينتقل إلى سطر جديد. النص يوضع بين علامتي تنصيص "..."، والفاصلة المنقوطة ; في النهاية تعني «انتهت هذه التعليمة» ويجب وضعها بعد كل تعليمة في ⁦C#⁩.
  3. Console.WriteLine("أنا أتعلم C#"); تعليمة ثانية من نفس النوع تطبع «أنا أتعلم ⁦C#⁩» في سطر جديد. الحاسوب ينفذ التعليمات بالترتيب من الأعلى إلى الأسفل، لذلك يظهر هذا السطر بعد الأول.
كل أمر في ⁦C#⁩ ينتهي بفاصلة منقوطة ; ونسيانها هو أكثر خطأ شائع عند المبتدئين. ولغة ⁦C#⁩ حساسة لحالة الأحرف: Console غير console.

⁦C#⁩ 
string name = "سارة";int age = 22;double gpa = 3.75;bool isStudent = true; Console.WriteLine($"الاسم: {name}");Console.WriteLine($"العمر: {age} - المعدل: {gpa}");Console.WriteLine($"طالبة؟ {isStudent}");
الاسم: سارة العمر: 22 - المعدل: 3.75 طالبة؟ True
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ ينشئ البرنامج أربعة متغيرات من أنواع مختلفة (نص، عدد صحيح، عدد عشري، صح/خطأ) ثم يطبع قيمها داخل جمل. سيرى الطالب: الاسم: سارة، ثم العمر والمعدل، ثم «طالبة؟ True».

  1. string name = "سارة"; هنا ننشئ «متغيرًا»، وهو صندوق في الذاكرة له اسم ويحفظ قيمة. الكلمة string تعني أن نوعه «نص»، واسمه name، والعلامة = تعني «ضع القيمة التي على اليمين داخل المتغير»، فيصبح name يحتوي على النص "سارة".
  2. int age = 22; الكلمة int تعني «عدد صحيح» أي عدد بدون كسور. أنشأنا متغيرًا اسمه age ووضعنا فيه 22، ولاحظ أن الأعداد لا توضع بين علامات تنصيص.
  3. double gpa = 3.75; الكلمة double تعني «عدد عشري» يمكن أن يحتوي على فاصلة عشرية. المتغير gpa يحفظ المعدل 3.75، ونكتب الفاصلة العشرية في الكود بنقطة دائمًا.
  4. bool isStudent = true; الكلمة bool نوع لا يحمل إلا قيمتين: true (صحيح) أو false (خطأ). المتغير isStudent يحفظ true أي «نعم، هي طالبة».
  5. Console.WriteLine($"الاسم: {name}"); العلامة $ قبل النص تسمح لنا بوضع متغيرات داخل النص بين قوسين معقوفين { }، وهذا يسمى «إدراج القيم في النص». عند التشغيل يُستبدل {name} بقيمته فيظهر: الاسم: سارة.
  6. Console.WriteLine($"العمر: {age} - المعدل: {gpa}"); يمكن إدراج أكثر من متغير في النص نفسه. هنا يُستبدل {age} بـ 22 و {gpa} بـ 3.75، فيظهر العمر والمعدل في سطر واحد.
  7. Console.WriteLine($"طالبة؟ {isStudent}"); عند طباعة متغير من نوع bool تكتب ⁦C#⁩ قيمته بالإنجليزية وبحرف كبير في أوله، فيظهر على الشاشة: طالبة؟ True.

قراءة مدخلات المستخدم

Console.ReadLine() يقرأ ما يكتبه المستخدم كنص دائمًا. لتحويله إلى رقم نستخدم int.Parse أو double.Parse.

⁦C#⁩ 
Console.Write("ما اسمك؟ ");string name = Console.ReadLine(); Console.Write("كم عمرك؟ ");int age = int.Parse(Console.ReadLine()); Console.WriteLine($"أهلًا {name}، بعد 5 سنوات سيكون عمرك {age + 5}");
ما اسمك؟ خالد كم عمرك؟ 20 أهلًا خالد، بعد 5 سنوات سيكون عمرك 25
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يسأل البرنامج المستخدم عن اسمه وعمره، ثم يرحب به ويخبره كم سيكون عمره بعد 5 سنوات. مثلًا إذا كتب «أحمد» و 20 يظهر: أهلًا أحمد، بعد 5 سنوات سيكون عمرك 25.

  1. Console.Write("ما اسمك؟ "); الأمر Write يطبع النص مثل WriteLine لكنه لا ينتقل إلى سطر جديد، فيبقى المؤشر بجانب السؤال ليكتب المستخدم إجابته في نفس السطر.
  2. string name = Console.ReadLine(); الأمر Console.ReadLine ينتظر حتى يكتب المستخدم شيئًا ويضغط Enter، ثم يعيد ما كتبه على شكل نص (string). نحفظ هذا النص في المتغير name لنستخدمه لاحقًا.
  3. Console.Write("كم عمرك؟ "); نطبع السؤال الثاني بنفس الطريقة، دون الانتقال إلى سطر جديد.
  4. int age = int.Parse(Console.ReadLine()); ReadLine يعيد دائمًا نصًا حتى لو كتب المستخدم أرقامًا، والنص "20" لا يمكن جمعه كعدد. لذلك نستخدم int.Parse الذي يحوّل النص إلى عدد صحيح int، وإذا كتب المستخدم شيئًا ليس عددًا يتوقف البرنامج برسالة خطأ.
  5. Console.WriteLine($"أهلًا {name}، بعد 5 سنوات سيكون عمرك {age + 5}"); داخل الأقواس { } في النص الذي يبدأ بـ $ يمكن وضع عملية حسابية وليس متغيرًا فقط. هنا {age + 5} يُحسب أولًا ثم تُطبع النتيجة، أما المتغير age نفسه فلا تتغير قيمته.
لعرض العربية بشكل صحيح في الكونسول أضف في أول البرنامج: Console.OutputEncoding = System.Text.Encoding.UTF8;

برنامج ترحيب

اطلب من المستخدم اسمه ومدينته، ثم اطبع: «مرحبًا [الاسم] من [المدينة]!».

اعرض الحل المقترح
⁦C#⁩ 
Console.Write("اسمك: ");string name = Console.ReadLine();Console.Write("مدينتك: ");string city = Console.ReadLine();Console.WriteLine($"مرحبًا {name} من {city}!");
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يسأل البرنامج المستخدم عن اسمه ومدينته ثم يطبع ترحيبًا يجمعهما، مثل: مرحبًا سارة من مسقط!

  1. Console.Write("اسمك: "); Console.Write يطبع السؤال ويترك المؤشر في نفس السطر حتى يكتب المستخدم بجانبه.
  2. string name = Console.ReadLine(); Console.ReadLine يقرأ ما يكتبه المستخدم حتى يضغط Enter ويعيده كنص، فنحفظه في المتغير name من نوع string.
  3. Console.Write("مدينتك: "); نطبع السؤال الثاني عن المدينة بنفس الطريقة.
  4. string city = Console.ReadLine(); نقرأ اسم المدينة ونحفظه في متغير نصي جديد اسمه city. لا نحتاج إلى تحويل هنا لأننا نريد نصًا أصلًا.
  5. Console.WriteLine($"مرحبًا {name} من {city}!"); النص الذي يبدأ بـ $ يسمح بإدراج المتغيرات بين { }، فيُستبدل {name} و {city} بما كتبه المستخدم ثم يُطبع السطر كاملًا.

مساحة المستطيل

اقرأ الطول والعرض (أعداد عشرية) واطبع المساحة والمحيط.

اعرض الحل المقترح
⁦C#⁩ 
Console.Write("الطول: ");double length = double.Parse(Console.ReadLine());Console.Write("العرض: ");double width = double.Parse(Console.ReadLine()); double area = length * width;double perimeter = 2 * (length + width);Console.WriteLine($"المساحة = {area}");Console.WriteLine($"المحيط = {perimeter}");
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يطلب البرنامج طول المستطيل وعرضه، ثم يحسب مساحته ومحيطه ويطبعهما. مثلًا مع طول 5 وعرض 3 يظهر: المساحة = 15 ثم المحيط = 16.

  1. Console.Write("الطول: "); نطبع طلبًا للمستخدم ليكتب الطول، ويبقى المؤشر في نفس السطر لأننا استخدمنا Write وليس WriteLine.
  2. double length = double.Parse(Console.ReadLine()); ReadLine يعيد نصًا، و double.Parse يحوّله إلى عدد عشري double حتى نستطيع إجراء الحساب عليه، ويقبل أعدادًا بكسور مثل 2.5. نحفظ النتيجة في المتغير length.
  3. Console.Write("العرض: "); نطلب من المستخدم إدخال العرض.
  4. double width = double.Parse(Console.ReadLine()); نقرأ العرض ونحوّله إلى عدد عشري بنفس الطريقة ونحفظه في width.
  5. double area = length * width; العلامة * تعني الضرب في ⁦C#⁩. نضرب الطول في العرض للحصول على المساحة ونحفظ الناتج في متغير جديد اسمه area.
  6. double perimeter = 2 * (length + width); الأقواس ( ) تجعل الجمع يُنفذ أولًا، ثم يُضرب الناتج في 2. بدون الأقواس كانت ⁦C#⁩ ستضرب 2 في length أولًا لأن الضرب يسبق الجمع، فتكون النتيجة خاطئة.
  7. Console.WriteLine($"المساحة = {area}"); نطبع المساحة بإدراج المتغير area داخل النص باستخدام $ والأقواس { }.
  8. Console.WriteLine($"المحيط = {perimeter}"); نطبع المحيط في سطر جديد بنفس الطريقة.

تحدٍّ: تحويل الحرارة

اقرأ درجة الحرارة بالمئوية وحوّلها إلى فهرنهايت بالمعادلة F = C × 9 / 5 + 32.

اعرض الحل المقترح
⁦C#⁩ 
Console.Write("الحرارة بالمئوية: ");double c = double.Parse(Console.ReadLine());double f = c * 9 / 5 + 32;Console.WriteLine($"{c}°C = {f}°F");
الحرارة بالمئوية: 30 30°C = 86°F
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يطلب البرنامج درجة الحرارة بالمئوية ويحوّلها إلى فهرنهايت. مثلًا إذا أدخل المستخدم 100 يظهر: 100°C = 212°F.

  1. Console.Write("الحرارة بالمئوية: "); نطبع طلبًا للمستخدم ليكتب درجة الحرارة، ويبقى المؤشر بجانبه لأننا استخدمنا Write.
  2. double c = double.Parse(Console.ReadLine()); نقرأ ما كتبه المستخدم كنص بـ ReadLine ثم نحوّله إلى عدد عشري بـ double.Parse، ونحفظه في المتغير c.
  3. double f = c * 9 / 5 + 32; هذه معادلة التحويل: ⁦C#⁩ تنفذ الضرب * والقسمة / أولًا من اليسار إلى اليمين، ثم الجمع + في الأخير. ولأن c من نوع double فالنتيجة تحتفظ بالكسور ولا تضيع.
  4. Console.WriteLine($"{c}°C = {f}°F"); نطبع القيمتين داخل نص واحد باستخدام $ و { }، والرموز °C و °F مجرد نص عادي يُطبع كما هو.
