SQL Server: إنشاء قاعدة البيانات والاستعلام

أهداف التعلم

في نهاية الدرس يستطيع المتدرب أن:

  • يشرح مفاهيم قاعدة البيانات: الجدول، العمود، الصف، المفتاح الأساسي.
  • ينشئ قاعدة بيانات وجدولًا في SQL Server باستخدام SSMS.
  • يختار نوع البيانات المناسب لكل عمود.
  • يضيف بيانات بـ INSERT.
  • يسترجع البيانات بـ SELECT مع WHERE وORDER BY.

شرح الدرس

1. ما هي قاعدة البيانات؟

قاعدة البيانات مكان منظم لحفظ البيانات بشكل دائم. البيانات توضع في جداول، والجدول له أعمدة (الحقول) وصفوف (السجلات). المفتاح الأساسي Primary Key عمود قيمته فريدة لكل صف، مثل رقم الطالب.

افتح SSMS ← اتصل بالخادم localhost\SQLEXPRESS ← New Query.

2. إنشاء قاعدة البيانات والجدول

أهم الأنواع: INT عدد صحيح، NVARCHAR(n) نص يدعم العربية، DECIMAL(5,2) عدد عشري، DATE تاريخ، BIT صح/خطأ.

SQL 
CREATE DATABASE TrainingDB;GOUSE TrainingDB;GO CREATE TABLE Students (    Id        INT IDENTITY(1,1) PRIMARY KEY,    FullName  NVARCHAR(100) NOT NULL,    Email     NVARCHAR(100),    Age       INT,    Course    NVARCHAR(50),    Grade     DECIMAL(5,2),    JoinDate  DATE DEFAULT GETDATE());
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ ينشئ هذا الكود قاعدة بيانات جديدة اسمها TrainingDB، ثم ينشئ بداخلها جدولًا اسمه Students لحفظ بيانات الطلاب. عند التشغيل لن ترى بيانات، بل رسالة تفيد بنجاح الأوامر وسيظهر الجدول الفارغ في قاعدة البيانات.

  1. CREATE DATABASE TrainingDB; الأمر CREATE DATABASE ينشئ قاعدة بيانات جديدة فارغة اسمها TrainingDB. قاعدة البيانات مثل خزانة كبيرة سنضع فيها جداول البيانات.
  2. GO الكلمة GO ليست أمر SQL حقيقيًا، بل إشارة لبرنامج SSMS بأن ينفّذ الأوامر التي قبلها كدفعة مستقلة قبل الانتقال لما بعدها. نحتاجها هنا حتى تُنشأ قاعدة البيانات فعلًا قبل أن نحاول استخدامها.
  3. USE TrainingDB; الأمر USE يجعل TrainingDB هي قاعدة البيانات الحالية، فكل الأوامر التالية ستُنفّذ بداخلها وليس في قاعدة بيانات أخرى.
  4. CREATE TABLE Students ( الأمر CREATE TABLE ينشئ جدولًا جديدًا اسمه Students. الجدول يشبه جدول Excel: له أعمدة (أنواع المعلومات) وصفوف (كل صف طالب). بين القوسين نكتب الأعمدة واحدًا تلو الآخر مفصولة بفواصل.
  5. Id INT IDENTITY(1,1) PRIMARY KEY, العمود Id رقم صحيح (INT). الخاصية IDENTITY(1,1) تجعل SQL Server يملؤه تلقائيًا بدءًا من 1 ويزيد 1 مع كل صف جديد، و PRIMARY KEY (المفتاح الأساسي) يعني أن قيمته لا تتكرر ولا تكون فارغة، فيُميّز كل طالب عن غيره.
  6. FullName NVARCHAR(100) NOT NULL, العمود FullName نصّ من نوع NVARCHAR(100) أي حتى 100 حرف، وحرف N يعني أنه يدعم كل اللغات ومنها العربية. أما NOT NULL فتعني أن هذا العمود إلزامي ولا يمكن ترك الاسم فارغًا.
  7. Email NVARCHAR(100), العمود Email نصّ حتى 100 حرف لحفظ البريد الإلكتروني. لم نكتب NOT NULL، لذلك يمكن تركه فارغًا (NULL) إذا لم يكن للطالب بريد.
  8. Age INT, العمود Age يحفظ عمر الطالب كرقم صحيح INT (بدون كسور).
  9. Course NVARCHAR(50), العمود Course نصّ حتى 50 حرفًا لحفظ اسم الدورة التي يدرسها الطالب.
  10. Grade DECIMAL(5,2), العمود Grade رقم عشري من نوع DECIMAL(5,2): مجموع خاناته 5 منها خانتان بعد الفاصلة، أي يمكنه حفظ قيم مثل 95.50 وحتى 999.99. نستخدمه لأن الدرجة قد تحتوي كسورًا.
  11. JoinDate DATE DEFAULT GETDATE() العمود JoinDate من نوع DATE لحفظ تاريخ الانضمام. الكلمة DEFAULT تعني قيمة افتراضية، و GETDATE() تعيد تاريخ اليوم؛ فإن لم نُدخل تاريخًا يُحفظ تاريخ يوم الإضافة تلقائيًا. لاحظ أنه آخر عمود فلا فاصلة بعده.
  12. ); القوس المغلق ينهي قائمة الأعمدة، والفاصلة المنقوطة تنهي أمر CREATE TABLE.
IDENTITY(1,1) يجعل SQL Server يولد رقم Id تلقائيًا: 1، 2، 3... ونضع N قبل النص العربي: N'سارة'.

3. إضافة البيانات INSERT

SQL 
INSERT INTO Students (FullName, Email, Age, Course, Grade)VALUES (N'سارة أحمد',  'sara@mail.com',  22, N'C#',   95), (N'خالد سالم',  'khaled@mail.com',25, N'HTML', 78), (N'مريم يوسف',  'maryam@mail.com',20, N'SQL',  88);
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ يضيف هذا الكود ثلاثة طلاب إلى جدول Students دفعة واحدة. عند التشغيل تظهر رسالة مثل (3 rows affected) أي تمت إضافة 3 صفوف.

  1. INSERT INTO Students (FullName, Email, Age, Course, Grade) الأمر INSERT INTO يضيف صفوفًا جديدة إلى الجدول Students، وبين القوسين نحدد الأعمدة التي سنعطيها قيمًا. لم نذكر Id لأن IDENTITY يملؤه تلقائيًا، ولا JoinDate لأن له قيمة افتراضية.
  2. VALUES الكلمة VALUES تعني: الآن تأتي القيم. كل مجموعة بين قوسين تمثل صفًا (طالبًا) واحدًا، وترتيب القيم يطابق ترتيب الأعمدة المذكورة أعلاه.
  3. (N'سارة أحمد', 'sara@mail.com', 22, N'C#', 95), هذا السطر والسطران بعده يمثّل كل واحد منها طالبًا. النصوص توضع بين علامتي تنصيص مفردة ' '، والبادئة N قبل النص تخبر SQL Server أنه نص Unicode حتى تُحفظ الحروف العربية صحيحة بدل علامات ؟؟؟. الأرقام تُكتب بلا علامات تنصيص، والصفوف تفصل بينها فاصلة.
  4. (N'مريم يوسف', 'maryam@mail.com',20, N'SQL', 88); آخر صف لا تأتي بعده فاصلة، بل فاصلة منقوطة تنهي أمر INSERT كله.

4. استرجاع البيانات SELECT

* تعني كل الأعمدة. WHERE تصفّي الصفوف، وORDER BY ترتّبها (DESC تنازليًا).

SQL 
SELECT * FROM Students; SELECT FullName, Grade FROM Students; SELECT * FROM Students WHERE Grade >= 80; SELECT * FROM Students WHERE Course = N'C#' AND Age < 25; SELECT FullName, Grade FROM Students ORDER BY Grade DESC; SELECT * FROM Students WHERE FullName LIKE N'م%';  -- يبدأ بحرف م
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ مجموعة من استعلامات SELECT لقراءة البيانات من جدول Students بطرق مختلفة: كل البيانات، أعمدة محددة، مع شروط، مع ترتيب، ومع بحث نصي. كل استعلام يعرض نتيجته في جدول مستقل.

  1. SELECT * FROM Students; الأمر SELECT يقرأ البيانات ويعرضها، والنجمة * تعني كل الأعمدة، و FROM Students تحدد الجدول. النتيجة: كل الطلاب بكل معلوماتهم.
  2. SELECT FullName, Grade FROM Students; هنا بدل النجمة كتبنا أسماء الأعمدة التي نريدها فقط، فتظهر النتيجة بعمودين: الاسم والدرجة.
  3. SELECT * FROM Students WHERE Grade >= 80; الكلمة WHERE تضع شرطًا لتصفية الصفوف، فلا يظهر إلا الطلاب الذين درجتهم أكبر من أو تساوي 80.
  4. SELECT * FROM Students WHERE Course = N'C#' AND Age < 25; الكلمة AND تجمع شرطين ويجب أن يتحقق كلاهما: الدورة هي ⁦C#⁩ والعمر أقل من 25. في SQL نستخدم علامة = واحدة للمقارنة.
  5. SELECT FullName, Grade FROM Students ORDER BY Grade DESC; الكلمة ORDER BY ترتّب النتائج حسب عمود معيّن، و DESC تعني تنازليًا (من الأكبر إلى الأصغر)، فيظهر صاحب أعلى درجة أولًا. بدونها يكون الترتيب تصاعديًا (ASC).
  6. SELECT * FROM Students WHERE FullName LIKE N'م%'; -- يبدأ بحرف م الكلمة LIKE تبحث عن نمط في النص، والرمز % يعني: أي عدد من الحروف (أو لا شيء). إذن N'م%' تعني كل اسم يبدأ بحرف م. والجزء بعد -- تعليق للتوضيح يتجاهله SQL Server.

سهل

اعرض الحل المقترح
SQL 
INSERT INTO Students (FullName, Email, Age, Course, Grade) VALUES (N'سارة', 's@mail.com', 22, N'C#', 95), (N'خالد', 'k@mail.com', 25, N'HTML', 78), (N'مريم', 'm@mail.com', 20, N'SQL', 88), (N'علي', 'a@mail.com', 23, N'C#', 55), (N'نورة', 'n@mail.com', 21, N'HTML', 91), (N'يوسف', 'y@mail.com', 24, N'SQL', 67);
شرح الكود سطرًا بسطر

ماذا يفعل هذا الكود؟ حل التمرين: إضافة ستة طلاب إلى جدول Students بأمر INSERT واحد. عند التشغيل تظهر رسالة (6 rows affected).

  1. INSERT INTO Students (FullName, Email, Age, Course, Grade) VALUES الأمر INSERT INTO يضيف صفوفًا إلى الجدول Students في الأعمدة المذكورة بين القوسين، ثم تأتي VALUES وبعدها القيم. لا نكتب Id لأنه يُولّد تلقائيًا.
  2. (N'سارة', 's@mail.com', 22, N'C#', 95), هذا السطر والسطران بعده ثلاثة طلاب، كل قوسين صف واحد بالترتيب: الاسم، البريد، العمر، الدورة، الدرجة. البادئة N قبل النصوص العربية ضرورية لحفظ الحروف العربية بشكل صحيح.
  3. (N'علي', 'a@mail.com', 23, N'C#', 55), هذا السطر والسطران بعده ثلاثة طلاب آخرون بنفس الترتيب. تفصل الفاصلة بين الصفوف، والصف الأخير ينتهي بفاصلة منقوطة لإنهاء الأمر.

  1. -- أ السطر الذي يبدأ بـ -- تعليق، أي ملاحظة للقارئ لا ينفذها SQL Server. استخدمناه هنا لترقيم أجزاء التمرين.
  2. SELECT FullName, Grade FROM Students ORDER BY Grade DESC; يعرض الاسم والدرجة لكل الطلاب مرتّبين بـ ORDER BY حسب الدرجة، و DESC تعني من الأعلى إلى الأدنى.
