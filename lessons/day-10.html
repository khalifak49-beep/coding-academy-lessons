  • يدمج HTML و⁦C#⁩ وSQL Server في مشروع واحد يعمل.
  • يشرح الكود الذي كتبه ويجيب عن أسئلة حوله.
  • يقيّم ما تعلمه ويعرف الخطوة التالية في رحلته.

شرح الدرس

1. قائمة التحقق قبل العرض

  • صفحة HTML تفتح وتعرض اسم النظام والنموذج والجدول بشكل منسق.
  • قاعدة البيانات موجودة وفيها 5 صفوف على الأقل.
  • برنامج ⁦C#⁩ يعمل بدون أخطاء، وكل خيارات القائمة تعمل.
  • جربت إدخال قيمة خاطئة (حروف بدل رقم) ولم يتوقف البرنامج.
  • جهزت 3 نقاط تريد أن تقولها: الفكرة، أصعب جزء، ماذا ستضيف لاحقًا.

2. طريقة العرض (5 دقائق)

  1. الفكرة ولمن هذا النظام (30 ثانية).
  2. صفحة HTML (دقيقة).
  3. قاعدة البيانات وتصميم الجدول في SSMS (دقيقة).
  4. تشغيل برنامج ⁦C#⁩ وتجربة: إضافة، عرض، تعديل، حذف، إحصائيات (دقيقتان).
  5. ما تعلمته وأصعب مشكلة واجهتها (30 ثانية).

3. ماذا بعد الدورة؟

الخطوات المقترحة: JavaScript لجعل الصفحات تفاعلية، ثم ASP.NET Core لبناء مواقع تتصل بـ SQL Server مباشرة، ثم Entity Framework Core. المهم الآن: اكتب كودًا كل يوم ولو 30 دقيقة.
