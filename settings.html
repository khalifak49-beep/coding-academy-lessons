طريقة إنشاء المفتاح (مرة واحدة، دقيقتان)

  1. افتح صفحة إنشاء مفتاح في GitHub وسجّل الدخول بحسابك.
  2. في Repository access اختر Only select repositories ثم المستودع khalifak49-beep/CodingAcademy.
  3. في Permissions ← Repository permissions اجعل Actions وContents على Read and write (إن لم تكونا مضبوطتين تلقائيًا).
  4. اضغط Generate token، انسخ المفتاح والصقه في الخانة أعلاه، ثم «حفظ والتحقق».

المفتاح ينتهي بعد 90 يومًا؛ أنشئ مفتاحًا جديدًا عندها. يمكنك إلغاؤه في أي وقت من إعدادات GitHub.
